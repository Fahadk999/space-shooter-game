How to Play:

Download main.zip.

Right-click the downloaded .zip file and select Extract All... (do not run directly from inside the zip file).

Open the extracted folder and double-click main.exe to launch the game!

Note for Windows Defender / SmartScreen:
If Windows displays a blue "Windows protected your PC" prompt when launching:

Click More info.

Click Run anyway.

(This warning appears automatically for new executables that aren't digitally signed with a paid publisher certificate, but the file is completely safe!)
